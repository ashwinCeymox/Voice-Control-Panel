## 2. Detailed Technical Fixes

### H1: Dev Key Removal & Explicit Admin Key
- Removed hardcoded default key `dev-voice-key-12345` from `app/core/security.py`.
- Added `settings.ADMIN_API_KEY`. When unconfigured, any incoming request without a valid registered key receives `401 Unauthorized`.
- Added startup validation in `app/main.py` ensuring that running in `APP_ENV=production` without an `ADMIN_API_KEY` raises a `RuntimeError` immediately during startup.

### H2: Strict CORS Invariants
- In `app/main.py`, CORS origins are strictly read from `settings.CORS_ALLOWED_ORIGINS` (defaults to localhost:5173 loopbacks).
- If wildcard `*` is supplied, `allow_credentials` is automatically set to `False` to prevent browser cross-origin credential hijacking.

### H3: Upstream Error Sanitization
- In `app/core/errors.py`, `app_error_handler` ensures that provider error bodies, upstream stack traces, and local filesystem paths (e.g. `/Users/.../models/whisper.yaml`) are logged to server stderr/logfiles only.
- The HTTP response payload returns only `{ "error": { "code": "<code>", "message": "<sanitized message>" } }`.

### H4: Transcript & Response Logging Privacy
- Configured `settings.LOG_TRANSCRIPTS: bool = False` by default.
- In `app/api/voice.py`, customer transcripts and LLM response tokens are only logged if `settings.LOG_TRANSCRIPTS` is explicitly set to `True`.

### H5: SQLite Concurrency Hardening (WAL Mode & Busy Timeout)
- In `app/storage/database.py`, both `init_db()` and `get_db()` execute:
  ```sql
  PRAGMA journal_mode = WAL;
  PRAGMA busy_timeout = 5000;
  PRAGMA foreign_keys = ON;
  PRAGMA synchronous = NORMAL;
  ```
- Tested with 5 concurrent writer coroutines simultaneously writing session records; completed with 0 database lock errors.

### H6: Safe Model Deletion & Shared Weight Protection
- In `app/api/gallery.py`, added helper `is_weight_file_shared(models_dir, weight_filename, excluding_config)` which inspects all YAML configuration files in the models directory.
- If a binary weight file (e.g. `llama-3.2-1b-instruct-q8_0.gguf`) is referenced by another installed model alias, deleting one configuration unlinks only its YAML file, retaining the shared binary weights.
- Path traversal guards (`..`, absolute paths outside `models_dir`) prevent deletion of unauthorized filesystem paths.

### H7: STT Fallback Disabled by Default
- In `app/core/config.py`, added `STT_ALLOW_FALLBACK: bool = False`.
- In `app/providers/localai_stt.py`, fallback loop to alternative Whisper models is gated behind `settings.STT_ALLOW_FALLBACK`.
- `TranscriptResponse` schema updated with `model: str` and `fallback_used: bool` fields so clients know exactly which model served the transcription.

### H8: Environment-Variable Driven Paths
- Scanned and eliminated all `/home/voiceagent/...` path strings from `app/core/config.py`.
- Replaced with dynamic lookups `os.environ.get("LOCALAI_MODELS_PATH")` and relative fallbacks.

### H9: Payload Length Limits
- Configured `settings.MAX_TTS_TEXT_CHARS = 2000` and `settings.MAX_AUDIO_DURATION_SECONDS = 120`.
- In `app/api/tts.py`, requests exceeding 2,000 characters are rejected with HTTP 413 `PayloadTooLargeError`.
- In `app/api/transcriptions.py`, file size limit is strictly checked before passing audio to the STT provider.

### H10: Granular Per-Endpoint Timeouts
- Configured separate timeout parameters in `app/core/config.py`:
  - `TIMEOUT_STT_SECONDS = 30.0`
  - `TIMEOUT_LLM_SECONDS = 60.0`
  - `TIMEOUT_TTS_SECONDS = 20.0`
  - `TIMEOUT_VOICE_TURN_SECONDS = 45.0`
- Replaced monolithic 120s timeout with endpoint-specific bounds.

### H11: API Documentation Toggle
- Configured `settings.ENABLE_DOCS: bool = False` by default.
- In `app/main.py`, FastAPI `docs_url`, `redoc_url`, and `openapi_url` evaluate to `None` unless `ENABLE_DOCS` is explicitly enabled.
