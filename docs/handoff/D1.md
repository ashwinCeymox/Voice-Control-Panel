## 2. Implemented Schema & Architecture

### Database Schema Updates (`app/storage/database.py`)
- **`profiles` table:**
  - `id` (TEXT PRIMARY KEY, e.g. `prof-xxxxxxxxxxxx`)
  - `name` (TEXT NOT NULL)
  - `description` (TEXT), `contact` (TEXT), `notes` (TEXT)
  - `disabled_at` (REAL nullable timestamp)
  - `created_at`, `updated_at` (REAL timestamps)
- **`api_keys` extensions:**
  - `profile_id` (TEXT references profiles)
  - `prefix` (TEXT, e.g. `va_live_xxxx...`)
  - `status` (TEXT DEFAULT 'active': active | paused | revoked)
  - `model_allowlist` (TEXT comma-separated models)
  - `ip_allowlist` (TEXT comma-separated CIDRs)
  - `rotated_from` (TEXT ID of previous key)
  - `rotation_expires_at` (REAL grace period expiry)
  - `last_used_at` (REAL timestamp updated on use)
- **`dashboard_settings` table:**
  - `id` (TEXT PRIMARY KEY, default 'default')
  - `base_url` (TEXT DEFAULT 'http://127.0.0.1:8000')
  - `default_rate_limit` (INTEGER DEFAULT 60)
  - `default_max_concurrent` (INTEGER DEFAULT 5)
  - `usage_retention_days` (INTEGER DEFAULT 30)
  - `updated_at` (REAL)
- **`admin_audit` table:**
  - `id` (INTEGER PRIMARY KEY AUTOINCREMENT)
  - `timestamp` (REAL), `admin_id` (TEXT), `action` (TEXT), `target_type` (TEXT), `target_id` (TEXT), `details` (JSON TEXT, no secrets or prompts)

## 4. Key Invariants & Security Guarantees

1. **One-Time Secret Exposure:** The plain secret API key is returned **strictly once** upon initial creation (`POST /v1/admin/keys`) or rotation (`POST /v1/admin/keys/{id}/rotate`). Thereafter, only slow HMAC-SHA256 hashes are stored and only the safe prefix (e.g. `va_live_ab12...`) is returned in lists and profile queries.
2. **Profile Disabling Invalidation:** When a profile is disabled (`disabled_at IS NOT NULL`), all API keys linked to that profile immediately fail authentication with HTTP 401 without deleting the keys.
3. **Key Pausing & Resuming:** Pausing a key (`status='paused'`) prevents caller authentication. Resuming (`status='active'`) immediately restores access.
4. **Model Allowlist Enforcement:** Caller requests to disallowed models in `/v1/chat/completions`, `/v1/audio/transcriptions`, and `/v1/text-to-speech/{voice}/stream` are rejected with HTTP 403 (`code: "FORBIDDEN"`).
5. **No Secrets in Audit Logs:** Audit events (`profile.create`, `key.create`, `key.rotate`, `settings.update`, etc.) log IDs, actions, and metadata, never plaintext keys or caller payloads.
