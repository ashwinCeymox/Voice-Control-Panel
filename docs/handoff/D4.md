## 1. Executive Summary

Task D4 delivers production-ready, copyable code templates for consuming applications and an interactive Docs & Snippets page in the control panel:
- **Corrected Gateway Endpoints:** All snippets strictly target the FastAPI gateway port 8000 with `Authorization: Bearer <key>` headers, keeping internal LocalAI (8080) and local-tts (8880) unreachable and protected.
- **Languages Supported:**
  - Python (`httpx`)
  - curl
  - JavaScript (`fetch`)
  - Official OpenAI Python SDK (`client.chat.completions.create` pointing `base_url` to local gateway)
- **Endpoints Covered:**
  - LLM Chat Stream (`/v1/chat/completions`)
  - STT Batch (`/v1/audio/transcriptions`)
  - STT Real-Time WebSocket (`/v1/audio/transcriptions/stream`)
  - TTS Audio Stream (`/v1/text-to-speech/{voice}/stream`)
  - Conversational Voice Pipeline WebSocket (`/v1/voice/stream`)
